# IC Tri website

Static website for the Imperial College Triathlon Club, built with [Hugo](https://gohugo.io/) and published with GitHub Pages.

**How everything works** (folder map, adding news/posts/people, GitHub setup, SEO, security):
read `content/blog/website-guide/index.md` — it is also published as a blog post on the website.

- Examples of every post feature: `content/blog/style-guide/index.md`
- Build & deploy: `.github/workflows/hugo.yml` (on every commit and nightly)
- Requires Hugo extended 0.167+ (only for local preview)
